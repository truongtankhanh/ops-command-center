15e Rules
Default off. The first run shows the full look; Calm is a per-person choice for long shifts.
Per browser. Remembered in local storage; a blocked store simply reads off.
3D only. The 2D map is already flat; the row is hidden where 3D is unavailable. The wall has no menu and stays full colour.
Every role. It changes how the scene looks, not what anyone may do.
No contrast loss. Labels and markers keep their ratios; only the backdrop calms.
