Model contract — one glTF file per asset class

CoolingTower               cooling_tower.glb · CT-01, CT-02 share it
├─ Casing                  static
├─ FanStack                static
│  └─ FanBlade             spin +Y · fanSpeedRpm
├─ FanMotor                state tint · motorTempC
├─ Pump                    state tint · pumpFlowM3h
├─ Pipe, Riser             static
├─ Valve                   turn X 0–90° · valveOpenPct
└─ ControlPanel            static
   └─ Switch               turn X ±35° · switchState
  • Name = the part role, English PascalCase, unique per file. Code finds it under each asset's instance root; artists never rename.
  • Pivot on the part's own axis of motion; +Y up, 1 unit = 1 m, origin at the asset's footprint centre.
  • extras on every bound node: bind (telemetry key), motion (spin, turn, slide or tint); on moving parts also axis and range (motion limits). The node name is the role.
